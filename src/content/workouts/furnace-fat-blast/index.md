  ## Program Overview 
  A 4-week fire-and-flame-themed CrossFit program designed for intermediate lifters who want to maximize fat loss and conditioning while holding onto muscle and strength. Each workout pays tribute to fiery elements and features dynamic engine work, metabolic conditioning, and classic lifts, using clever names and weekly progression to keep things stoked.
